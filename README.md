## 🔍 Overview

A comprehensive **customer data analysis** project that dives deep into customer demographics, transaction patterns, and purchasing behavior. The analysis covers the full pipeline — **data cleaning → exploratory analysis → customer scoring → segmentation → actionable insights** — to help businesses identify high-value customers, understand segment performance, and drive data-informed strategies.

## ✨ Key Features

- **🧹 Data Cleaning & Preprocessing** — Handling missing values, type conversions, and merging master data with transaction records
- **📈 Customer Base Analysis** — Profiling demographics, distribution of customers across segments, and geographic patterns
- **💰 Purchase Value Metrics** — Analyzing average order value, total spend, purchase frequency, and revenue trends
- **🏅 Customer Scoring** — Building composite scoring models to rank customers by value and engagement
- **📊 Segment Performance** — Evaluating performance across customer segments with comparative visualizations
- **💎 High-Value Customer Contribution** — Quantifying the revenue share and behavioral traits of top-tier customers
- **🎯 Insights & Recommended Actions** — Data-driven recommendations for retention, upselling, and growth strategies

## 🚀 How to Use

1. **Clone the repository**
   ```bash
   git clone https://github.com/s0-umya/Python-Customer-Data-Analysis.git
   cd Python-Customer-Data-Analysis
   ```

2. **Install dependencies**
   ```bash
   pip install pandas matplotlib seaborn jupyter
   ```

3. **Launch the notebook**
   ```bash
   jupyter notebook notebooks/Customer_Data_Analysis.ipynb
   ```

4. **View the report** — Open `reports/Customer_Data_Analysis.html` in any browser for a static view of the complete analysis.
